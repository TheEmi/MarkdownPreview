# Inkflow

A split-screen Markdown studio: write on the left, preview on the right, copy HTML in one click.

## Features

- Live Markdown → HTML preview (GFM, sanitized)
- **Copy HTML** (also `Ctrl/Cmd+Shift+E`)
- Formatting toolbar + shortcuts (`Ctrl/Cmd+B`, `I`, `K`)
- Resizable split, editor/preview-only modes
- Optional scroll sync
- Light / dark theme
- Draft auto-saved in `localStorage`
- Download `.md` or `.html`
- Word / character / line counts

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
